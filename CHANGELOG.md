## Unreleased

- **[2026-07-18] First playable prototype: Ensign Ace vs. Admiral Anchor** — a local, Editor-only build where you can move, aim, and fight as either Sailor. Ace fires a ranged 3-shot Jump Serve burst; Anchor swings a close-range Anchor Slam that knocks enemies back, and once its Super charges up, leaps in with Drop Anchor for impact damage plus a temporary damage-reduction shield for nearby allies. Knockouts end the match. Keyboard/mouse only for now — no touch controls or on-device build yet, and the arena is a placeholder greybox, not the real Tideline Cove.
- **[2026-07-18] Bootstrap the Unity project** — Unity 6000.5.4f1 LTS opened and building for Android: IL2CPP/ARM64, URP, Input System (New), custom base Gradle template (kotlin-stdlib duplicate-class fix), Optimized Frame Pacing disabled (Swappy/Vulkan emulator crash workaround). Confirmed running on `Pixel_9_API_35` emulator.
